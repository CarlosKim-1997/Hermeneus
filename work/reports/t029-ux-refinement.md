## 경험 개선

- 전달함: 초안/확정 버전과 다음 행동을 구분한다. ID는 관리 정보로 옮기고,
  private title의 비공개 범위를 표시한다. 확정 버전을 공유 중이라고 오인시키지 않는다.
- 준비: 안내문 복사를 먼저 보여주고 세 단계 진행 표시를 추가한다. 원문 import는
  펼침형 보조 경로로 옮기되 원문 저장을 설명한다.
- 미리보기/검토: 한국어 행동·분류명을 사용하고 미리보기/저장/확정의 차이와
  미저장 상태를 표시한다. 미수집 원문 패널을 접어 편집 영역을 확보한다.
- 확정/공유: 버전 확정과 링크 발급을 구분한다. 버전 고정, 단회 링크 표시,
  접근 해제 완료 상태를 설명한다.
- 수신: 확정 내용과 내 AI 주경로를 나란히 배치하고 사이트 질문을 보조로 구분한다.
  현재 수동 자료 전달과 목표 MCP 경험을 계획에서 분리한다.
- 검사: provider off 안내를 입력 전에 유지한다. 판정 설명·원래 코드·검사 원문·버전을
  함께 보여주며 PARTIAL/INDETERMINATE를 정합 성공으로 표시하지 않는다.
- 관리/복구: 원문만/전달 전체/계정 삭제의 범위, 정확한 DELETE와 기존 확인 단계를
  유지한다. 로그인/loading/error/404와 계정 식별 정보도 정리한다.
- 공통: 색·간격·분류 badge·버튼·입력·focus 스타일, ko 언어와 본문 바로가기,
  작은 화면 배치를 통일한다. payload·schema·enum·공개 의미는 유지한다.

## 동작 보강과 내부 적대적 검토

1. 원문 수정 중 오래된 검사 응답이 새 답변에 붙는 경로를 generation 확인으로 차단했다.
   응답을 지연시킨 시험에서 결과가 되살아나지 않음을 확인했다. 답변/동의 저장은 추가하지 않았다.
2. 질문·근거 조회의 네트워크 실패에 try/finally와 오류 표시를 추가했다. 공유 생성/해제의
   결과가 불명확하면 목록 재확인을 안내하고 자동 재시도나 성공 표시를 하지 않는다.
3. 한국어 번역 후 첫 항목/항목, 전체 제안/제안 버튼이 기존 E2E의 부분 일치에 동시에
   잡혔다. 정확한 접근성 이름을 사용하도록 시험을 수정했다.
4. E2E의 “해제” 조건이 “접근 해제” 버튼에 먼저 일치해 실제 해제 전에 이동하는 문제가
   있었다. 완료 상태를 “해제됨”으로 구분해 완료를 기다린다. 원문 삭제 후 패널 재마운트도
   실제 상태가 도착한 뒤 펼치도록 시험을 수정했다.

검토 범위는 UI diff와 동의·버전·원문 결합·공유/삭제 경계다. 제3자 독립 보증이나
전체 보안 감사가 아니다. backend 인증/삭제/DB 계약은 바꾸지 않았다.
