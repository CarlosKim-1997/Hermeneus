# Governance snapshot

This directory contains the repository-owned Governance protocol. `SPEC.md` is normative; `schemas/` summarizes record shapes; `manifest.yaml` selects the adopted protocol and Current State. Project-specific authority lives in `canon/`. Tasks and reports live in `work/`. Run `node tooling/governance/check.mjs` from the repository root for deterministic structural validation. A PASS does not prove semantic correctness.
